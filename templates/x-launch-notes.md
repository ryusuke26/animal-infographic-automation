# X向けの準備メモ

2026-09-05のレビューを受けたローカルの下書き。プロフィール変更、固定、
投稿、返信はまだ実行していない。日次制作の必須作業にはしない。

自己紹介の候補:

```text
世界の知らない生きものを、出典つきのイラスト図鑑で紹介。姿・習性・ちょっと不思議な暮らしを少しずつ。AIで制作し、資料と照合しています。
```

固定投稿の候補（採用済み日本語作品を1枚添付）:

```text
名前も知らなかった生きものに、ひとつ驚く。
そんな小さな発見を、イラスト図鑑にしています。

姿や習性、暮らす場所を、出典と一緒に紹介。
気になった一匹から、のぞいてみてね。
```

最初の実験:

- 次の新作から日本語本文には日本語ポスター1枚を添付する。
  英語版は必要に応じて別の返信で紹介する。追加画像は生成しない。
- 約2週間、同じ形式で試す。本文の改善は開始前に反映し、実験中は
  投稿時間やタグなど別の条件を意図的に同時変更しない。
- 24時間後の表示回数、いいね、返信、リポストだけ既存のメモに記録。
  URLと投稿時刻も残す。表示回数はユニーク人数ではない。
- 比較するなら同じ経過時間の複数投稿の中央値を見る。題材や曜日の
  違いがあるため、少数例から因果関係や増加率を断定しない。
- 好きな生き物の投稿へ具体的な感想や質問を返す時間を、余裕がある日に
  5〜10分。自動返信、無関係な宣伝、反応の交換は行わない。
- 過去作を別の切り口で紹介する場合は、既存の出典と現在の状態を確認。
  新作選定の重複除外と、意図的な再紹介を区別する。

制作改善の効果は、各パッケージの既存QAメモに初回採用／再生成理由を
短く残して比較する。現時点で失敗率やインプレッション改善は未測定。
