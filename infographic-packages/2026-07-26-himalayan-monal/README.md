## Topic Lock

- English common name: Himalayan Monal
- Japanese common name: ニジキジ
- Scientific name: *Lophophorus impejanus*
- Broad native region: Asia
- Lineage: pheasant family, Phasianidae
- Habitat: Himalayan forest near the treeline, alpine shrubland, and meadows
- Curiosity hook: the adult male changes from green to blue and purple as
  iridescent feathers catch the light, then shifts elevation with the seasons
