# Japanese X Post Copy

## Main post

```text
海の闇に、青く光る“丸い歯あと”。
ダルマザメ
Isistius brasiliensis

暖かい外洋を、昼は深く、夜は海面近くへ。
腹側が青く光る、全長50cmほどの小さなサメです。
大きな魚やクジラから丸い一片をくり抜く、ちょっと不思議な暮らし。

IUCN Red List 2017：低懸念（LC）
#世界の知らない生き物
```
