# 140-Character Thread Drafts

## Japanese

1. 川底で、緑の髪みたいな藻をまとうカメ。カクレガメ / Mary River Turtle です。#世界の知らない生き物

2. 学名は Elusor macrurus。オーストラリア・クイーンズランド州のメアリー川だけにすむ淡水ガメです。

3. 長い尾、大きな水かき、藻をまとった甲羅。水中の酸素も使える、ちょっと不思議な暮らし。

4. IUCN Red List 1996: Endangered (EN)。個体数は書かず、川の暮らしと特徴に絞りました。

## English

1. A turtle that can wear algae like green hair: the Mary River Turtle, Elusor macrurus.

2. It is known only from Queensland's Mary River system, where it lives in freshwater river habitat.

3. Look for the low shell, big webbed feet, very long tail, and soft green algae on the head and shell.

4. IUCN Red List 1996: Endangered (EN). No population number used; the post stays discovery-first.
