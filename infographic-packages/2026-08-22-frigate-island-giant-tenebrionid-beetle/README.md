## Locked scope

- Accepted name: *Polposipus herculeanus* Solier, 1848.
- English public name: Frigate Island Giant Tenebrionid Beetle.
- Japanese public display name: フレガット島オオゴミムシダマシ; no established Japanese standard common name was confirmed, so this is a transparent descriptive rendering of the supported English name.
- Global status: IUCN Red List Vulnerable (VU) under D2, assessed 16 November 2013 and published in 2014.
- Public claims: adults use Frégate's coastal woodland trees by day, the dark rounded abdomen is strongly tubercled, and larvae develop while feeding in rotten wood.
- Discovery doorway: a large flightless beetle spends daylight on tree trunks, descends after dark to forage, and begins its next generation inside a fallen log.
