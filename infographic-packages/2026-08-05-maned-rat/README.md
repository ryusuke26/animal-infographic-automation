## Evidence route

The user-supplied official IUCN species-page screenshot and matching seven-page assessment PDF directly confirm a Global Least Concern (LC) assessment under *Lophiomys imhausi* and the IUCN English name `Crested Rat`: assessed 31 January 2016, published 2016, record `e.T12308A22368581`, DOI `10.2305/IUCN.UK.2016-2.RLTS.T12308A22368581.en`. The current Mammal Diversity Database accepts *Lophiomys imhausii* and identifies *Lophiomys imhausi* as an incorrect subsequent spelling. Public identity lines retain the current accepted name and `Maned Rat`, while the source notes explain the official IUCN aliases.
