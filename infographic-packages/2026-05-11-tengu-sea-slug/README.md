## Rationale

This run moves away from the recent deep-sea sponge, Australian earthworm, Madagascar gecko, and parasitic plant topics. The chosen doorway is a tiny tropical sea slug that looks leaflike on algae and is often nicknamed a "leaf sheep." The package keeps the exact species identity anchored to the Japanese common name and scientific name because online "leaf sheep" images can mix similar *Costasiella* species.
