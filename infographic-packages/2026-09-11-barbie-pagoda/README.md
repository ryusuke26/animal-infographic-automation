## Locked scope

- Accepted name: *Podoserpula miranda* Buyck, Duhem, Eyssartier & Ducousso. No taxonomic synonym was found for duplicate screening; the earlier 2009 provisional name is the same species, not another accepted taxon.
- English public name: Barbie Pagoda, supported by the original description and IUCN publications.
- Japanese public name: バービー・パゴダ, a transparent transliteration; no standardized Japanese mycological-list name was confirmed.
- Global status: IUCN Red List Critically Endangered (CR) under C2a(ii), assessed 25 July 2019, record `T154605211A154605228`.
- Public claims: one axis carries five to six progressively smaller funnel caps; fruit bodies are reported only during wetter El Niño events; records come from the base of oak gum trunks in southern New Caledonia.
- Discovery doorway: a tiny pink-lilac pagoda briefly rises from the wet forest floor.

## Production status

- Evidence Lock and bilingual cards-v2 Copy Lock are complete.
- Two exact-taxon photographs, their RGB-compatible reference copies and one official range screenshot are retained locally. Only the two photograph pairs are identity references.
- The taxonomic literature places the species in Amylocorticiales; the IUCN mirror still displays Boletales. Public copy avoids the order name.
- Province Sud describes ectomycorrhizal symbiosis with oak gum, while the IUCN assessment says the species is potentially parasitic. Public copy states only the shared, directly observed trunk-base association.
- The Japanese first generation passed the source gate but added two duplicate labels inside Card 1's diagram. One localized Image Gen edit removed only those labels; the accepted source preserves the hero, all nine locked strings and the three card illustrations.
- The English first companion passed the source gate. One localized typography review edit was made after the handwritten font drew the two Card 3 apostrophes with a curved shape; the accepted image keeps the correct spellings and punctuation positions while preserving the whole composition.
- Four canonical PNGs are exact 1024 x 1536 and pixel-identical within language. Direct-source, X-format, package, full-size, phone-size, attachment, growth-form, false-silhouette, typography, card, composition and whitespace QA pass.
- The exact selected prompts are [image-prompt-ja.md](image-prompt-ja.md) and [image-prompt-en.md](image-prompt-en.md). Published to GitHub in package content commit `9829ea5`; nothing was posted to X.
