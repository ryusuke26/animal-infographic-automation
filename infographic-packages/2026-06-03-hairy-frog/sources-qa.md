Overall: Ready with taxonomy caveat.

Use *Trichobatrachus robustus* in public copy because it is the familiar/IUCN-facing name, but record that AMNH Amphibian Species of the World currently places the species as *Astylosternus robustus*.

## Publication-Safe Copy

ケガエル / Hairy Frog (*Trichobatrachus robustus*) is introduced as a Central African forest-stream frog. Breeding males can develop hair-like skin papillae on the flanks and thighs; the poster calls them skin, not fur. Bony toe-claw anatomy is included as a quiet observation note, not horror content. Conservation footer: IUCN Red List 2017: Least Concern (LC).

## Notes

- Taxonomy caveat: AMNH ASW currently treats the accepted combination as *Astylosternus robustus*. IUCN and many public sources still use *Trichobatrachus robustus*. To keep public copy recognizable, final captions use *Trichobatrachus robustus* and the README records the caveat.
- Direct IUCN page rendering was not available through the browse view, but the species URL, taxon ID, 2017 assessment year, LC category, and DOI-format reference are consistent across indexed references.
- Avoid overclaiming the function of the papillae. The package only states the visible structure in poster copy.
- Image guidance: show a robust frog with papillae on flanks/thighs, wet forest stream stones, and webbed feet. Do not show actual fur, monster claws, a salamander, or a toad-like warty body.
