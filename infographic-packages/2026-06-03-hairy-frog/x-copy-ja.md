# X Copy - Japanese

## Main Post

森の渓流で、雄だけが“毛”をまとって見える。
Hairy Frog
*Trichobatrachus robustus*

中央アフリカの森や渓流にすむカエル。繁殖期の雄には、体側と後肢に毛のような皮膚突起が出ます。
本物の毛ではなく、血管の通った皮膚。
足先にも、ちょっと不思議な暮らしの道具をかくしています。

IUCN Red List 2017: Least Concern (LC)

#世界の知らない生き物

## ALT Text

クレヨンとオイルパステル風の縦長ポスター。濡れた石とコケのある森の渓流で、茶色からオリーブ色のがっしりしたケガエルが座っている。体側と後肢には毛のように見える細い皮膚突起があり、足先には骨質の爪を示す小さな注記がある。注記は、繁殖期だけ毛のような皮膚、森の渓流でくらす、足先に骨質の爪をかくす。下部に IUCN Red List 2017: LC とある。
