## Rationale

Central America/Caribbean had zero appearances in the latest eight completed packages, while North America had two and was the immediately preceding region. This topic adds an eastern-Cuban terrestrial gastropod, tree-and-shrub habitat, bark-grazing ecology, and shell-color variation without repeating a recent lineage or habitat.

The discovery doorway is visual and natural-history-first: a living land snail whose rounded shell carries vivid, widely varying bands while it moves among lichens on tree bark.
