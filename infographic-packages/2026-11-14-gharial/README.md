This bilingual, curiosity-first package introduces the Gharial (*Gavialis gangeticus*), a fish-eating crocodilian whose adult males carry a pot-shaped knob, the ghara, on the tip of an extremely slender snout. It uses exactly three numbered, illustrated vignettes and a quiet global-status footer.
