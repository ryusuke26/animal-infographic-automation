## Evidence route

The accepted name and English common name are supported by Australia's DCCEEW and the Australian Faunal Directory route exposed through ALA. IUCN assessment `T19951A123379010` is Global Critically Endangered, assessed 11 February 2019; the official DOI is exact, while the direct assessment body was blocked by Cloudflare in this run and is cross-checked against the current IUCN 2025-2 mirror. DCCEEW supports the Edgbaston Springs range, wetlands less than 8 cm deep, maximum size of about 3 cm, daily temperature variation of up to 27°C, and the bright red fins displayed by breeding males.
