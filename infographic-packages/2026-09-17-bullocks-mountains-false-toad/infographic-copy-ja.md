# Japanese Copy Lock

Copy format: cards-v2

Title: ブロックヤマモドキヒキガエル
Scientific name: *Telmatobufo bullocki*

Observation cards:
1. Heading: 急流に吸いつく口
   Explanation: オタマジャクシは吸盤状の口と太い尾をもち、急流の岩につく。
2. Heading: 沢を離れ、森の中へ
   Explanation: 繁殖後の成体は森へ入り、沢から約500m先でも見つかった。
3. Heading: 黄色い帯が顔のしるし
   Explanation: 成体はオリーブ褐色で、目の間を横切る黄色い帯をもつ。

Footer/status:
IUCN Red List 2015: 絶滅危惧 (EN)
