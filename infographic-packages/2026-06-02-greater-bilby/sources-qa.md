# Sources QA - Greater Bilby

## Verdict

Overall: Ready.

The package avoids population numbers and separates global IUCN status from Australian legal status. Public copy uses the global footer only: `IUCN Red List 2016: Vulnerable (VU)`.

## Notes

- No current, geographically scoped population number is used.
- No map is used; the current range is fragmented and would be easy to oversimplify.
- "ミミナガバンディクート" is used as the Japanese poster title because it foregrounds the visible trait. The English post names Greater Bilby directly.
- Image identity cautions: avoid rabbit-like bodies, kangaroo posture, mouse-like short snout, missing digging claws, and tail without the black-white contrast.
