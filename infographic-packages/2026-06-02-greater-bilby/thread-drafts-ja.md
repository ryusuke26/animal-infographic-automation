# 140-Character Thread Draft - Japanese

1. 砂の夜に、長い耳だけが先に目をさます。ミミナガバンディクート（Greater Bilby）です。#世界の知らない生き物

2. オーストラリアの乾いた草地や低木地でくらす有袋類。夜に出て、地面を掘りながら虫・種・菌類などを探します。

3. 長い耳、細い鼻、強い前足、白黒の尾が目印。昼は深い、らせん状の巣穴で休みます。

4. IUCN Red List 2016: Vulnerable (VU)。個体数ではなく、今日は砂の下のちょっと不思議な暮らしに注目。

5. 出典: IUCN Red List、Australian Government SPRAT/DCCEEW、Australian Museum、Animal Diversity Web。
