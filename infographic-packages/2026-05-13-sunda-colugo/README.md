# Sunda Colugo / マレーヒヨケザル package

Date: 2026-05-13

Package status: needs final visual approval

## Rationale

Selected to move away from the recent marine-invertebrate sequence and into an arboreal Southeast Asian mammal. The curiosity hook is a living "gliding cloak": a nocturnal mammal that is neither a bat nor a true lemur, but moves through forest canopy on a furred membrane.

## Topic

- Japanese common name: マレーヒヨケザル
- English common names: Sunda Colugo, Sunda Flying Lemur, Malayan Flying Lemur
- Scientific name: *Galeopterus variegatus*
- Broad taxonomy: Animalia; Chordata; Mammalia; Dermoptera; Cynocephalidae; *Galeopterus*
- Status used in public copy: IUCN Red List 2008: Least Concern (LC)

## Image QA

- Image Gen raster posters were regenerated for Japanese and English after the first draft was flagged as anatomically weak.
- Dimensions: Japanese 1024 x 1536; English 1024 x 1536.
- Draft v1 issue: the animal read too much like a generalized flying-squirrel/lemur-like glider, with a simplified triangular membrane and unclear limb-to-tail anatomy. Draft v1 files are preserved as `*_draft_v1_2026-05-13.png`.
- Regenerated v2 improved surface cues but was also rejected after review: the full-spread gliding pose still melts limbs, tail, and patagium into an impossible cloak-like body. Draft v2 files are preserved as `*_draft_v2_2026-05-13.png`.
- Regenerated v3 uses a safer side-on clinging posture on a tree trunk, with the folded patagium visible as a continuous furred edge from neck to limbs and tail. It avoids the full-glide pose and is the current package-local candidate. Final publication still needs human visual approval.
- Generated text is readable, but package copy and text-safe backups remain authoritative.
- Text-safe SVG and PNG backups are included for exact wording.
- No population number, fake map, blame framing, rescue framing, or urgency slogan is used.
