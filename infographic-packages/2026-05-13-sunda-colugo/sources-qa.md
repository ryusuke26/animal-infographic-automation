# Sources and QA

## Source Notes

- Mammal Diversity Database was used for the accepted species page, taxonomy, distribution countries, IUCN status display, and hidden-diversity caution.
- IUCN status is cited as Boeadi & Steinmetz 2008 via DOI `10.2305/IUCN.UK.2008.RLTS.T41502A10479343.en`. The public footer uses the assessment year and category only.
- Animal Diversity Web provides range, rainforest/arboreal habitat, nocturnal behavior, patagium details, diet, and maternal membrane note. Its page title uses `variegates`, so spelling was not taken from ADW.
- NParks provides concise identity guidance for the membrane, tree-clinging/gliding behavior, diet, and Singapore habitat context.
- Mason et al. 2016 and the MDD taxonomy note are used only to flag possible hidden diversity inside current *Galeopterus variegatus*; no public copy claims a split species.

## Image Identity Guidance

Show a small-to-medium arboreal mammal, not a bat, not a true lemur, not a monkey, and not a flying squirrel. Key visual cues: large forward eyes, small ears, blunt snout, mottled lichen-like gray-brown fur, claws on all feet, and a broad furred membrane from neck through limbs to tail.

## QA

- No population number included.
- No "only X left" framing.
- No fake distribution map.
- No blame, rescue, or command language.
- Conservation/status is a quiet footer.
- Text-safe backups contain exact public copy.
