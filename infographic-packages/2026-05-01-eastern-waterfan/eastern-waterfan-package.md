# Eastern Waterfan / Appalachian Waterfan Infographic Package

Run date: 2026-05-01 JST  
Topic: Eastern Waterfan / Appalachian Waterfan, `Peltigera hydrothyria`

## 1. Species / Topic Selection Rationale

Eastern Waterfan is a good curiosity-first subject because it looks like a leafy fan but is actually a lichen growing on rocks in cool, shaded streams. It gives the viewer a clean discovery hook: some lichens are not dry crusts on bark, but living sheets in moving water. It is also overlooked enough to feel unfamiliar, while still having strong source coverage from IUCN, Canadian species-at-risk materials, NatureServe, and peer-reviewed taxonomy work.

I avoided population-number claims because available public summaries use regional occurrence and status language more safely than a current, simple global count. The final copy keeps conservation context to one quiet footer line.
