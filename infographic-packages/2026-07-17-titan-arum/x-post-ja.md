## Main post

```text
森の底で、深紅のひだをひらく大きな花序。
ショクダイオオコンニャク / Titan arum
Amorphophallus titanum

スマトラ島の低地熱帯林、石灰岩の斜面に根を張る植物。
一つの巨大な花に見えて、小さな花を集めた花序です。
開花の夜、熱とにおいで虫の送粉者を呼ぶ、ちょっと不思議な暮らし。

IUCN Red List 2018: Endangered (EN)
#世界の知らない生き物
```

## ALT text

```text
縦長の自然観察ポスター。スマトラの湿った低地熱帯林の石灰岩斜面に、ショクダイオオコンニャクが一本立つ。中央には淡い黄緑色の肉穂花序、その根元を深いえんじ色でひだのある仏炎苞が包む。周囲に、熱帯林と石灰岩、小花の集まり、熱とにおいに集まる小さな虫を示す1〜3のカード。下部にIUCN Red List 2018: Endangered (EN)とある。
```
