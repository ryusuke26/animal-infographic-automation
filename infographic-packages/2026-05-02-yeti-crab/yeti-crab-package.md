# 世界の知らない生きもの: Yeti crab / イエティクラブ

Run date: 2026-05-02  
Topic: Yeti crab / イエティクラブ / *Kiwa hirsuta*

## Selection rationale

深海の熱水噴出域で見つかった、白く毛深い「カニ」のような甲殻類。見た目の入口が強い一方で、実体はヤドカリ類に近いスクワットロブスターで、剛毛・細菌・暗黒の熱水環境という自然史の要素が短い投稿に収まる。保全を前面に出さず、「光の届かない場所でどう暮らすか」を見せられるので今回向き。
