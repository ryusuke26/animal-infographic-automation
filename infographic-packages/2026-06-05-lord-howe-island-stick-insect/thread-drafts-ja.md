# 140字スレッド案（日本語）

1. 岩の夜に、黒いナナフシが歩いている。ロードハウ島ナナフシ、*Dryococelus australis*。

2. ロードハウ島の近く、Ball's Pyramidの岩場に残る、大きくて羽のないナナフシです。

3. 夜に葉を食べ、昼は岩のすき間へ。岩棚と細い葉に寄り添う、ちょっと不思議な暮らし。

4. IUCN Red List 2017: CR。数の話で煽らず、まずはこの生きものの形と場所を見てみる回。

5. 出典：IUCN/Phasmida Species File、DCCEEW、NSW Environment and Heritage、Australian Museum。
