# X投稿文（日本語）

## Main Post

岩の夜に、黒いナナフシがまだ歩いている。
Lord Howe Island Stick Insect
Dryococelus australis

ロードハウ島の近く、Ball's Pyramidの岩場で夜に葉を食べる、大きくて羽のないナナフシです。
昼は岩のすき間に身をひそめます。
夜の岩棚を歩く、ちょっと不思議な暮らし。

IUCN Red List 2017: Critically Endangered (CR)

#世界の知らない生きもの

## ALT Text

クレヨンとオイルパステル風の縦長ポスター。夜のBall's Pyramidの岩棚に、黒褐色で太い体、長い触角、6本の脚をもつロードハウ島ナナフシがいる。周囲には岩のすき間と細い緑の葉が描かれ、「夜の岩棚で葉を食べる」「昼はすき間にかくれる」「羽のない大きなナナフシ」「IUCN Red List 2017: CR」と書かれている。

## Optional Source / Context Reply

出典メモ：IUCN Red List 2017（CR）は Phasmida Species File の記載で確認。生息場所や岩のすき間・Melaleuca との関係は DCCEEW と NSW の資料を参照。
