# Sources and QA - Lord Howe Island Stick Insect

## Verdict

Overall: Ready for publication with conservative wording.

The package uses *Dryococelus australis*, Lord Howe Island Stick Insect / Lord Howe Island Phasmid, and IUCN Red List 2017: Critically Endangered (CR). Public copy avoids population numbers because wild estimates and survey reports are highly date- and scope-dependent.

## Image Identity Guidance

- Use a robust, dark brown to black, wingless stick insect body.
- Six legs, long antennae, thick cylindrical abdomen, smooth segmented body.
- Night setting on volcanic rock, sparse green tea-tree/Melaleuca-like leaves, rock crevices.
- Avoid lobster claws, crab legs, mantis forelegs, centipede body segments, generic twig insect thinness, fake maps, and population icons.

## Source Notes

- DCCEEW page is an older conservation advice page last updated 2021-10-03 and contains historical federal-listing wording; use it for range/habitat narrative, not as the only current legal-status statement.
- NSW final determination from 2012 provides strong morphology and habitat detail, but its population numbers are dated and not used in public copy.
- Phasmida Species File provides the accessible IUCN 2017 CR cross-check in this environment.
- ABC News 2026 is useful to know that field context changed recently, but it is not the formal Red List reassessment.
