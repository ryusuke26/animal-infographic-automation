## QA

- 全5ページ: 1024x1536、縦2:3。
- スノーくん: 緑の葉なし、赤い肉質の花序、重なる鱗片状の苞を全ページで維持。
- 5ページ目: 小さな鐘形の赤桃色の花と淡色の花芯を表示。
- 菌糸ちゃん: 白い分岐糸として地下に表示し、傘のあるキノコにはしていない。
- 4ページ目の初稿は花序まで地下に置かれたため不採用。採用版では花序を地上、根と菌糸を地下に修正した。
- 炭素の流れ: 太陽光・木の葉 → 木の根 → 菌糸 → スノープラントの根、の順で表示。
- 「ごはん」「バトン」「菌糸ちゃんのやさしさ」は幼児向けの比喩。本文メモで、実際には木が固定した炭素が菌類を介して移る関係だと明記。
- 文字は各ページのロック済み本文を読みやすい下部ボックスに配置。句読点や引用符の字形は生成画像内で組版上の差があるが、意味と本文は一致。
- ロゴ、透かし、保全スローガン、脅威・個体数表現なし。
