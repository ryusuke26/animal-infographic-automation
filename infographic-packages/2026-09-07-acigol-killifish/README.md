## Locked scope

- Accepted name: *Anatolichthys transgrediens* (Ermin, 1946); historical combinations are retained for duplicate screening.
- English public name: Acigöl Killifish, following the current IUCN assessment. The local place name is Acıgöl.
- Japanese public display name: アジュギョル・キリフィッシュ. No established standard Japanese common name was confirmed; this is a transparent rendering of the supported English name.
- Global status: IUCN Red List Critically Endangered (CR) under B2ab(i,ii,iii,iv,v), assessed 4 July 2023, record `T1850A135082408`.
- Public claims: it moves through a steep salinity gradient around Lake Acıgöl; it is endemic to tiny spring areas of that single basin; a reference-matched individual has a pale grey body with irregular dark bars and a slightly upturned lower jaw.
- Discovery doorway: a tiny barred fish follows the narrow seam where freshwater springs meet a hypersaline inland lake.
