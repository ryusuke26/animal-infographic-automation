## Maintenance Rules

- Read automation memory first, then this index, then package folder names.
- Add every completed run here with topic, scientific name, package path, status, and one operational note.
- Begin each new completed entry's Notes with a broad native region such as `Region: Africa`, `Region: Asia`, or `Region: Australia/Oceania`.
- Before selecting a topic, count broad regions across the most recent 8 completed entries. Prefer unused regions and avoid any region already appearing 2 or more times when a credible alternative exists.
- Avoid the same broad region in consecutive runs. Australia/Oceania remains on cooldown until the rolling rule allows it again.
- If a run is partial, put it under "Incomplete" instead of "Completed".
- Do not rely on `generated_images` as the archive of record.
- Keep package slugs and filenames ASCII.
