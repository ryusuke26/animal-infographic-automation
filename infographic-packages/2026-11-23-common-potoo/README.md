# Common Potoo / ハイイロタチヨタカ

Status: **completed, local-ready** (2026-11-23; no GitHub or X action)

Workflow mode: `Quality Run`

Editorial classification group: `Birds`

Broad region: Central and South America (Nicaragua to Argentina/Uruguay, Trinidad and Tobago) — woodland edges, savanna and semi-open country with scattered trees

Package date: 2026-11-23 (Asia/Tokyo)

This bilingual, curiosity-first package introduces the Common Potoo (*Nyctibius griseus*), a nocturnal bird that freezes upright on a broken branch tip with its bill pointed at the sky and watches through slits in its closed eyelids. It uses exactly three numbered, illustrated figures and a quiet global-status footer.
