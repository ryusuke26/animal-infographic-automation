## Japanese Thread

1. 川をまたぐ、一本の糸。ダーウィンズ・バーク・スパイダー *Caerostris darwini*。#世界の知らない生き物

2. マダガスカルの川の上に円い網を張る、樹皮色の小さなクモ。流れの上にも、狩りの場所がある。

3. 報告例では、岸をつなぐ糸は最大約25 m。水上を飛ぶ虫を待つ、ちょっと不思議な暮らし。

4. IUCN 公開検索(2026): 種評価を確認できず。出典: J. Arachnology 2010 / PLOS ONE 2010。

## English Thread

1. A single thread crosses the river: Darwin's Bark Spider, *Caerostris darwini*. #NaturalHistory

2. This small bark-coloured spider suspends an orb web above waterways in Madagascar.

3. Reported anchor threads reach about 25 m, creating a hunting place above flowing water.

4. IUCN public search (2026): no species assessment located. Sources: J. Arachnology 2010 / PLOS ONE 2010.
