# Japanese Copy Lock

Copy format: cards-v2

Title: リーフィーシードラゴン
Scientific name: *Phycodurus eques*

Observation cards:
1. Heading: 葉っぱは、ヒレじゃない
   Explanation: 海藻そっくりの皮弁は泳ぐヒレではなく、体の輪郭を隠す。
2. Heading: 透明なヒレで進む
   Explanation: 首もとの胸びれと背中の背びれを細かく動かして泳ぐ。
3. Heading: 卵を持つのは、オス
   Explanation: メスが尾の腹側へ卵を渡し、オスがふ化まで抱える。

Footer/status:
IUCN Red List 2016: 低懸念 (LC)
