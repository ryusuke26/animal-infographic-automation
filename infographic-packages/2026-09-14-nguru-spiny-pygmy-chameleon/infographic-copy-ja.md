# Japanese Copy Lock

Copy format: cards-v2

Title: ヌグルコノハカメレオン
Scientific name: *Rhampholeon acuminatus*

Observation cards:
1. Heading: 小さな体に、鋭い突起
   Explanation: 頭から背に並ぶ突起が、葉のような輪郭をつくる。
2. Heading: 雄の鼻先は、下へ伸びる
   Explanation: 成熟した雄は、雌より大きな吻の突起をもつ。
3. Heading: 薄明の森、その低い層へ
   Explanation: 落ち葉や低い植物の間で、明け方や夕方に動く。

Footer/status:
IUCN Red List 2013: 深刻な危機 (CR)
