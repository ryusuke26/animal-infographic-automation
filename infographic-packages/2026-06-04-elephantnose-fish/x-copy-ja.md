# X Copy - Japanese

## Main Post

くらい川底で、鼻みたいなあごがそっと動く。
Elephantnose Fish
*Gnathonemus petersii*

西・中央アフリカの流れのゆるい川や、泥と水草のある川底にすむ淡水魚。
鼻に見えるのは、下あごから伸びる器官。
暗い水の中を弱い電気で探る、ちょっと不思議な暮らし。

IUCN Red List 2019: Least Concern (LC)

#世界の知らない生き物

## ALT Text

クレヨンとオイルパステル風の縦長ポスター。泥と水草のある暗い川底を、黒っぽく細長いエレファントノーズフィッシュが横向きに泳いでいる。下あごから細い鼻のような器官が伸び、口はその上にある。注記は、くらい川底をすいすい、あごの小さな鼻で探る、弱い電気でまわりを感じる。下部に IUCN Red List 2019: LC とある。
